# 5240 PcOff Agent — 테스트 모드 사용 가이드

비개발자·QA가 로컬에서 시업/종업/이석·임시연장·긴급사용 등을 재현할 때 참고하는 문서입니다.

---

## 1. 테스트 모드란?

- **운영과 분리된 개발자 전용 기능**입니다.
- 서버 API 없이, **로컬에서 정해진 값**으로 시업 전·종업·이석·임시연장·긴급사용 등 화면과 동작을 **바로 재현**할 수 있습니다.
- **트레이 메뉴에는 테스트 모드 버튼이 없습니다.** 개발자 모드이므로 **핫키로만** 켜고 끕니다.

---

## 2. 테스트 모드 켜기/끄기

| 동작 | 방법 |
|------|------|
| **켜기** | **Ctrl+Shift+T** (Windows) / **Cmd+Shift+T** (macOS) |
| **끄기** | 같은 키 다시 입력: **Ctrl+Shift+T** / **Cmd+Shift+T** |

- 테스트 모드가 켜지면 **에이전트 작동정보 화면 상단**에  
  **「테스트 모드 ON (Ctrl+Shift+T로 해제)」** 문구가 보입니다.
- 이 문구가 보이면 **지금은 테스트용 설정**이 적용된 상태라는 뜻이니, 실제 업무용으로 사용 중이 아닌지 확인하세요.

---

## 3. 테스트 모드 설정 패널(Drawer)

- 테스트 모드가 **ON**일 때만 **우측 Drawer(테스트 모드 설정)** 가 나타납니다.
- Drawer에서 할 수 있는 것:
  - **화면 타입·동작 모드** 선택 (시업 전 / 종업 / 이석 등)
  - **시간·근태 값** 직접 입력 후 **값 적용**으로 반영
  - **잠금화면 문구·리소스(선택)**: 시업 전/종업/이석별 제목·안내 문구·배경 URL·로고 URL 입력 시 테스트 잠금화면에 그대로 적용됨. 비우면 서버/config 값 사용.
  - **프리셋 버튼**으로 자주 쓰는 시나리오를 한 번에 폼에 채우기
  - **시작** 버튼으로 현재 설정을 적용하고, 필요 시 잠금화면까지 열기

---

## 4. 프리셋과 [시작] 버튼

- **프리셋 버튼**을 누르면 **폼만 채워집니다.** (아직 적용되지 않음)
- **적용·잠금화면 실행**을 하려면 반드시 **[시작]** 버튼을 눌러야 합니다.

| 프리셋 | 의미 |
|--------|------|
| 시업 전 | 시업 전 잠금 화면 재현 |
| 종업 | 종업 잠금 화면 재현 |
| 이석(사유 필수) | 이석 잠금 + 사유 입력 필요 |
| 이석(사유 면제) | 이석 잠금 + 사유 면제 |
| 일반 / 임시연장 / 긴급사용 / 긴급해제 | 동작 모드만 강제 |
| 초기화 | 화면 타입·모드·입력값 초기화 |

프리셋 선택 → (필요 시 값 수정) → **[시작]** 클릭 순서로 사용하세요.

---

## 5. 주의사항

1. **테스트 모드 ON 배너**  
   상단에 「테스트 모드 ON」이 보이면 테스트 설정이 적용된 상태입니다. 실제 업무용이 아닌지 꼭 확인하세요.

2. **잠금 해제 시 테스트 모드 자동 해제**  
   테스트 모드로 연 잠금화면에서 **PC-ON 등으로 잠금 해제**를 하면, **테스트 모드가 자동으로 OFF**됩니다.  
   (다시 테스트하려면 **Ctrl+Shift+T** / **Cmd+Shift+T**로 다시 켜면 됩니다.)

3. **프로그램 시작 시**  
   앱을 새로 실행하면 **처음에는 테스트 모드가 항상 OFF**입니다. 이전에 켜 두었어도 자동으로 꺼진 상태로 시작합니다.

4. **운영 환경**  
   배포용 설정(`config.json`에서 `allowTestMode: false`)으로 두면 테스트 모드(핫키 포함)가 비활성화됩니다. 일반 사용자 PC에서는 테스트 모드가 동작하지 않습니다.

|------|------|
| 테스트 모드 ON/OFF | **Ctrl+Shift+T** / **Cmd+Shift+T** (트레이 메뉴에는 버튼 없음) |
| 설정 패널 | 테스트 모드 ON일 때만 우측 Drawer 표시 |
| 적용·잠금 실행 | 프리셋 또는 값 입력 후 **[시작]** 버튼 클릭 |
| 잠금 해제 시 | 테스트 모드 자동 OFF |
| 앱 재시작 시 | 테스트 모드 OFF 상태로 시작 |
